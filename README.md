# 教練學員管理

單頁網頁 APP（`index.html`），功能：

- 學員基本資料建置
- 教練上課紀錄
- 學員簽到
- 合約上傳與保存（含到期提醒）

直接用瀏覽器開啟 `index.html` 即可使用；資料預設存在該瀏覽器本機（localStorage / IndexedDB）。

## 資料儲存（Google 試算表）

APP 右上「連線」可連到你自己的 Google 試算表（透過 `apps-script/Code.gs` 部署的 Apps Script 網頁應用程式）。
學員、上課紀錄、簽到存在試算表；合約檔案存在你的雲端硬碟「學員合約」資料夾。
連線網址與金鑰只存在每支手機的瀏覽器裡，本 repo 不含任何資料或金鑰。
未連線時，資料只存在該瀏覽器本機。
